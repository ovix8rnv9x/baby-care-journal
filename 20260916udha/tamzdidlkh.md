# 提前8-10年预警阿尔茨海默病！免费公益筛查，别错过→

> 更新时间：2026-09-16 (UTC+8)

点击箭头处“蓝色字”，关注我们哦！！

您是否觉得自己记性变差了？

经常忘记刚刚说过的话或自己放置的物品，做事丢三落四？

是否感觉家人脾气变差了变得很难沟通，或反应迟钝？

我们总认为这些表现可能是年龄大了属于正常衰老现象，但其实这些都是大脑发出的“求救信号”，可能是阿尔茨海默病（简称AD，俗称老年痴呆）早期的表现。许多人的观念里，AD一旦发现，往往已经是中晚期，此时进行治疗患者的症状很难得到改善。

如果做一份量表、抽一管血，就能提前8-10年预见未来的风险，您愿意给父母或自己做一个脑健康体检吗？

即日起，河南中医药大学第一附属医院脑病中心记忆门诊启动“脑健康公益筛查行动”，为您和家人筑起记忆的防线！

**Ø 为什么要提前预警？**

很多人会问：“现在没有症状，为什么要查？”

因为研究发现，在AD出现的症状的前10多年，其标志性病理产物Aβ和Tau蛋白已经开始在脑组织内出现异常沉积。而传统的检测方法包括腰椎穿刺进行脑脊液的检测，或进行PET-CT检查，要么有创、要么价格昂贵，难以作为常规的筛查手段。如今，随着检测技术的革新，通过外周静脉采血就能精准分析血液中与AD相关的6项核心标志物。

**Ø 这项筛查结果准确吗？**

本次筛查的核心内容包括AD相关6项血液生物标志物，其中p-tau181、p-tau217被称为AD“特异性”指标，能精准区分阿尔茨海默病与其他痴呆病，甚至在认知完全正常时即可升高；Aβ42/Aβ40比值，是反映脑组织中Aβ的“风向标”；NfL是反映脑神经元损伤的关键指标；GFAP能够反映脑部神经炎症的情况，与AD疾病进展速度密切相关。

**Ø 筛查流程复杂吗？**

第一步：认知测评。由记忆门诊专业医师进行量表测评，全面评估认知功能。

第二步：采集静脉血。无需空腹，简单便捷。

第三步：出具风险报告。结合认知测评+血液标志物的双维度数据，医生将为您解读：

1.当前大脑功能状态（正常/轻度认知障碍/痴呆）。

2.未来8-10年罹患AD的风险概率。

3.个体化干预方案（包括中医药调理、饮食和运动等生活方式指导）。

**Ø 哪些人群可以参加？**

如果您或您的家人存在以下情况，建议抓住此次公益机会：

1. 年龄在55岁以上的人群。

2. 自觉有明显的健忘或记忆力下降者。

3. 有AD家族史者（直系亲属中有确诊患者）。

4. 有高血压、糖尿病、高脂血症、长期失眠等慢性病史者。
