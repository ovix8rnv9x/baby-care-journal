# 当表彰大会邂逅艺术党课：北大医院这样为医学生“铸魂”

> 更新时间：2026-09-16 (UTC+8)

日月其迈，时盛岁新。12月19日下午，北京大学第一医院“辞旧迎新，思政铸魂”学生艺术党课暨奖学金颁奖会在筑梦厅举行。活动将庄重的奖学金表彰与沉浸式艺术党课深度融合，以表彰先进、树立榜样为核心目标，通过创新形式筑牢青年医学生的理想信念之基。党委书记姜辉，院长杨尹默，医学部学生工作部副部长张红梅，医院党委副书记、纪委书记赵瑞萍，副院长杨莉、李航，院长助理焦红梅，学生党总支书记、党院办主任史楠，各职能处室负责人、学工队伍老师、获奖学生代表及教师代表齐聚一堂，共赴这场集荣誉激励、艺术熏陶与思想淬炼于一体的盛会。

团委副书记、风湿免疫科黄红和2018级八年制博士生谭程浩共同主持活动

**荣誉时刻**

**榜样引领，星光闪耀育人路**

姜辉书记代表医院党委向全体获奖学子表示祝贺，向辛勤育人的教职工致以敬意。他提到，2025年医院正式成立学生工作部，成为北京大学首家设立专职学生工作部门的临床医学院，这一体制创新，有力推动了学生党建与思政教育、管理服务的深度融合，是落实立德树人根本任务、响应新时代思政工作要求的关键举措，标志着医院人才培养进入了系统化、专业化的全新阶段。姜书记强调，思政教育必须根植于发展实践。他回顾了北大医院110年来为国家医学事业做出的开创性贡献，重点介绍了医院近年通过“调结构、促增量，强学科、重人才，抓运营、强管理”取得的丰硕成果，门急诊量持续高速增长、科研成果丰硕，今年更荣获 “全国文明单位” 这一国家级荣誉。这些由全体北大医院人奋斗得来的成就，为思政课提供了最鲜活的教材。姜书记表示，在过去一学年中同学们在各自的赛道上奋力奔跑，闪耀着新时代医学青年的璀璨光芒，是各个领域的“守护者”、“攀登者”、“服务者”、“践行者”，号召大家以榜样为镜，珍惜荣誉、见贤思齐，同时希望全院教职员工继续携手同心，以“三全育人”的格局共同守护青年成长之路。

随后，史楠主任宣读了《关于表彰北京大学第一医院2024-2025学年度奖学金获得者的决定》。本学年，全院共有535人次优秀学子凭借在学业、临床、科研、服务等领域的卓越表现获得殊荣，其中167人获得校级及以上奖学金，117人获得院级奖学金。同学们以无私奉献的专业态度守护患者健康，以严谨求真的精神深耕学术、探索未知，以医者担当用点滴善举传递温暖正能量，以默默付出搭建师生沟通桥梁，以热忱服务凝聚集体力量，更以青春姿态绽放多元才华，用拼搏奋进展现全面发展风采。他们将个人成长与医学事业紧密相连，生动诠释了“健康所系，性命相托”的铮铮誓言，深刻践行了北大医院“厚德尚道”的精神内核。

学生党总支副书记、学生工作部部长赖丽娜主持颁奖环节

国家奖学金、校长奖学金、五四奖学金、厚道奖学金，校级优秀医学生系列奖学金，以及首届院级奖学金——竞赛之星奖学金、厚德奖学金、临床奉献奖学金、学术进步奖学金、学工服务奖学金等奖项逐一颁发。颁奖嘉宾为获奖学生代表颁发荣誉证书，台下掌声雷动，这是对每一位获奖同学过去一年辛勤付出的充分肯定与有力激励。希望全体同学都能以获奖同学为榜样，在医学之路上笃行不怠，绽放属于自己的光彩！

2025级专业型博士生王世琦作为获奖学生代表发言。他表示，今天能够作为代表站在这里，内心充满感恩。这份荣誉不仅是对每一位在医学道路上默默耕耘的获奖同学的集体褒奖，更承载着医院对青年医学生的悉心栽培与殷切期望。他承诺，北大医院学子将始终坚守“健康所系，性命相托”的誓言，用专业的医术、温暖的爱心，诠释新时代医学生的责任与担当，不辜负医院的培养与患者的信任！

杨尹默院长在总结讲话中再次向获奖同学表示热烈祝贺，向全体育人工作者致以衷心感谢。他深刻阐述了学生成长与医院发展的同频共振关系，特别分享了医院高质量发展的振奋消息，全院门急诊总量已突破450万人次，大兴院区启用两周年交出了聚焦“五大中心”建设、锻造硬核医疗队伍的亮眼答卷。这份沉甸甸的“大兴答卷”所展现的开拓进取、务实笃行的文化内核，正是“厚德尚道”院训精神的时代彰显，也必将为未来医学栋梁的成长提供丰厚沃土。杨院长寄语全体同学，以身边榜样为引领，精益求精、全面发展，个人医学理想融入到健康中国建设和医院发展大局，在未来的从医道路上，把今天的荣誉化为明日继续攀登的动力，戒骄戒躁，追求卓越；同时希望全院教师具备更强的责任感、更实的举措、更多的创新，共同营造更好的育人环境，为同学们搭建更广阔的成长平台。

**艺术洗礼**

**沉浸观演，红色基因薪火传**

颁奖环节结束后，活动进入第二部分——原创沉浸式艺术党课《西山红色交通线》。该剧以致敬抗战胜利80周年为主题，通过四幕史诗叙事，深情再现了抗战时期国际友人贝熙业等先辈，冒着生命危险由西山交通线运送药品物资、传递关键情报、支援抗战前线的感人故事。舞台上，演员们富有张力的表演将观众瞬间带入那个战火纷飞却信仰如炬的年代。剧中诸多源于真实历史的细节刻画，让英雄人物愈发有血有肉、鲜活可感，令在场师生无不为之动容。艺术党课实现了红色基因从“入眼入耳”到“入脑入心”的升华。

**融合创新**

**铸魂育人，启航时代新征程**

本次“艺术党课暨奖学金颁奖会”是北大医院深化“三全育人”改革、创新思想政治工作的又一次生动实践。活动成功将价值引领、荣誉激励与文化熏陶有机融合，探索出一条内涵丰富、实效显著的思政教育新路径。表彰先进，树立的是医术与医德并重的青年标杆；艺术演绎，传承的是忠诚、信仰与奉献的精神火种，让思政教育既有力度更有温度。

展望未来，北大医院将始终坚守为党育人、为国育才的初心使命，在上级领导的指导与支持下，以更完善的育人体系、更创新的教育模式，助力每一位医学青年将个人理想融入健康中国建设的宏伟事业，着力培养更多医德高尚、医术精湛、可堪大任的时代新人，在守护人民健康、推动医学事业发展的征程中，书写无愧于时代、无愧于青春的壮丽华章！
